Privacy Policy

Effective date: 3 October 2026

StoryFactory ("the tool") is a private video production tool operated by Fernando Rampon ("the operator") to publish videos to YouTube channels he owns. This policy explains what data the tool accesses, how it is used, stored and deleted, and how access can be revoked.

Use of YouTube API Services

StoryFactory uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using StoryFactory you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Who the data belongs to

The tool has a single user, the operator, and only connects to YouTube channels the operator owns. It does not offer accounts to the public and does not collect data from viewers, commenters or any other third party.

Data accessed through Google sign-in

When the operator authorizes a channel with Google OAuth, the tool receives an access token and a refresh token for that channel with the following permissions:

  • Manage the channel's videos and settings (youtube, youtube.upload, youtube.force-ssl): upload the operator's own videos, set their metadata, schedule, thumbnails, captions and playlists, and apply the channel's description, keywords and banner.
  • Read the channel's reports (yt-analytics.readonly, yt-analytics-monetary.readonly): views, watch time, subscribers, impressions, click-through rate and revenue of the operator's own channels.

The tool also reads the channel's basic information (channel ID, title, playlists) and the status of its own uploaded videos.

How the data is used

  • to publish and schedule the operator's videos and keep their settings correct;
  • to show the operator a private dashboard with the performance of his channels and to plan future videos (for example, replacing a thumbnail with a low click-through rate).

The data is never sold, shared with third parties, used for advertising, or combined with data from other users.

Storage and security

  • OAuth tokens are stored only on the operator's own computer, in a local folder that is not synchronized to any cloud service, and are never transmitted anywhere except to Google's own API endpoints.
  • Channel and video statistics are stored in a local database on the same computer.
  • No data obtained from YouTube API Services is stored on any server operated by StoryFactory; there is none.

Retention and deletion

  • Statistics obtained from YouTube API Services are refreshed or deleted within 30 days, except derived metrics and publicly available statistics kept as allowed by the YouTube API Services Developer Policies.
  • When the operator stops using a channel with StoryFactory, its tokens and the data obtained from YouTube API Services for it are deleted from the local computer.
  • The operator can delete all stored data at any time by deleting the tool's local data folder.

Revoking access

Access granted to StoryFactory can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the tool can no longer access the channel.

Cookies

This website does not use cookies or tracking. The tool itself does not place cookies on any device other than the operator's own browser profile.
